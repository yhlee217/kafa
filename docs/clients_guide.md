# 수임처 속성 조사표 — 만들고 반영하기

담당자만 아는 사실(개인/법인·직원 유무)을 받아 `config/clients.yaml` 로 만든다.
왜 필요한지: `docs/domain_notes.md` (직원이 없으면 복리후생비가 성립하지 않는다 등).

## 1) 이름을 미리 채워서 조사표 만들기

담당자가 수임처 이름을 100번 타이핑하지 않도록, **이미 있는 목록에서 이름을 뽑아** 채운다.

```bash
# (권장) 위하고 거래처 목록 엑셀에서
#   위하고 › 거래처관리 › 좌측 하단 '가져오기 및 내보내기' › 내보내기 → 엑셀 저장
kafa-clients template 수임처_조사표.xlsx --from-excel 거래처목록.xlsx

# 이미 고객별 폴더를 만들어 뒀다면
kafa-clients template 수임처_조사표.xlsx --from-inbox C:\kafa\inbox

# 직접 적은 목록(한 줄에 하나)
kafa-clients template 수임처_조사표.xlsx --from-list 목록.txt

# 이미 처리한 이력이 있다면
kafa-clients template 수임처_조사표.xlsx --from-db C:\kafa\out\kafa.db
```
여러 개를 함께 줘도 되고, 중복은 자동으로 걸러진다.
이름 컬럼은 헤더(`거래처명`·`상호`·`업체명` 등)를 보고 **구조로** 찾으므로 양식이 달라도 된다.

## 2) 담당자가 채운다

`수임처` 시트에서 **개인/법인**, **직원 있나요?** 만 고르면 된다(드롭다운). 업종·비고는 선택.
사업자번호 같은 민감정보는 적지 않아도 된다. 작성 방법은 파일 안 `작성방법` 시트에 있다.

## 3) 반영

```bash
kafa-clients import 수임처_조사표.xlsx --out config/clients.yaml
```
이후 파이프라인이 **고객별로** 개인/법인을 적용하고, 직원 없는 수임처에 복리후생비가
추천되면 검토 플래그를 남긴다. 미등록 수임처는 `defaults` 값을 쓴다(동작은 막히지 않음).
