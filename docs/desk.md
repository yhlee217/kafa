# 아버님 PC 에서 쓰기 — 처리하기 · 업로드본 만들기

아버님 사무실 PC(Windows)에서 쓰는 방법입니다. 매달 하는 일은 **파일 넣기 → 처리하기 →
답지 확인 → 업로드본 만들기 → 위하고에 올리기** 다섯 가지입니다. 답지에서 고른 계정은 다음 달부터
같은 가맹점에 자동으로 쓰입니다.

위하고 자료는 아버님이 직접 내려받습니다. 위하고가 로그인에 이메일 인증을 넣은 뒤로 자동 수집은
쓰지 않습니다(docs/decisions.md 2026-11-26).

## 폴더

`C:\Users\<이름>\kafa` 안에 이렇게 있습니다.

| 폴더·파일 | 무엇 | 아버님이 하는 일 |
|---|---|---|
| `1_받은자료\<수임처>\` | 위하고 '신용카드' 다운로드 파일 | 수임처 폴더에 파일을 넣는다 |
| `처리하기.bat` | 답지와 클로드에게 보낼 파일을 만든다 | 더블클릭 |
| `2_클로드\` | 클로드에게 보낼 질문 파일과 붙여넣을 말 | 클로드에 올리고, 받은 답을 여기 넣는다 |
| `3_답지\답지.xlsx` | 계정을 확인·수정하는 표 | '확정 계정'을 확인하고 저장 |
| `업로드본_만들기.bat` | 답지대로 업로드본을 만든다 | 더블클릭 |
| `4_업로드본\<수임처>\<달>\` | 위하고에 올릴 .xls 와 검토 리포트 | 위하고에 올린다 |
| `_내부\` | 처리 이력·클로드 답 모음·처리 끝난 원본 | 손대지 않는다 |

## 매달

1. **파일 넣기** — 위하고에서 수임처마다 '신용카드' 자료를 엑셀로 내려받아 `1_받은자료\<수임처>\` 에 넣습니다.
   새 수임처면 폴더를 새로 만들면 됩니다(폴더 이름이 수임처 이름이 됩니다).
2. **처리하기** — `처리하기.bat` 을 더블클릭합니다. `3_답지\답지.xlsx` 가 생깁니다.
3. **클로드(새 질문이 있을 때만)** — 화면에 "클로드에게 물을 것이 N가지" 가 나오면
   - `2_클로드\클로드에게_보낼_질문.json` 을 Claude Desktop(또는 Cowork)에 올리고,
     `클로드에게_붙여넣을_말.txt` 의 내용을 붙여넣습니다.
   - 클로드가 준 답을 `2_클로드\` 에 넣습니다. 파일로 받았으면 그대로, 대화창에 글로 받았으면
     메모장에 붙여넣어 아무 이름의 `.txt` 로 저장하면 됩니다.
   - `처리하기.bat` 을 한 번 더 누르면 답지에 클로드 추천이 채워집니다.
   - 이 단계는 건너뛰어도 됩니다. 그러면 처음 보는 가맹점은 답지에서 직접 고르시면 됩니다.
4. **답지 확인** — `답지.xlsx` 를 열어
   - **확정 계정**: 들어 있는 계정이 그대로 올라갑니다. 틀리면 목록에서 고릅니다. 비어 있으면 계정 없이(미해소) 올라갑니다.
   - **확정 유형**: 카과(공제)·일반(불공제)·카면(면세). 프로그램이 정한 유형('추천 유형')이 미리 들어 있습니다.
     틀리면 목록에서 고릅니다. 계정을 정한 행에만 반영됩니다.
   - **올리지 않음**: 업로드하지 않을 건(업무무관 등)은 '예'.
   - **메모**: 자유롭게.
   - 저장하고 **엑셀을 닫습니다**.
5. **업로드본 만들기** — `업로드본_만들기.bat` 을 더블클릭합니다. `4_업로드본\` 에 .xls 가 생깁니다.
6. **위하고에 올리기** — 위하고 '신용카드 매입 엑셀 업로드'에서 그 .xls 를 올립니다.

답지에 나오는 건은 프로그램이 계정을 못 정했거나, 추천했거나, 확인 표시가 붙은 건뿐입니다. 위하고가
이미 계정을 채운 건은 나오지 않고 그대로 올라갑니다.

## 지켜 주실 것

- **이미 올린 달의 파일은 다시 넣지 마세요.** 같은 전표가 두 번 올라갑니다.
- **답지에는 거래처 이름이 있습니다. 클로드에 올리지 마세요.** 클로드에게는 `2_클로드` 의 질문 파일만
  올립니다(업태·종목·품명·유형과 건수뿐입니다).
- 행 수·금액이 안 맞는 파일은 업로드본을 만들지 않고 멈춥니다. 화면에 '실패' 가 나오면 아드님께 알려 주세요.

## 막힐 때

| 화면에 나온 말 | 할 일 |
|---|---|
| 답지가 엑셀에서 열려 있습니다 | 엑셀을 닫고 다시 누른다 |
| 답지에서 고칠 곳이 있습니다 — N행 확정 계정 '…' | 그 행의 계정을 목록에서 다시 고르고 저장 |
| 답지에서 고칠 곳이 있습니다 — N행 확정 유형 '…' | 카과·일반·카면 중에서 고르고 저장 |
| 답지와 파일 내용이 다릅니다 | `처리하기` 부터 다시(답지를 새로 만든다. 이미 고친 칸은 남는다) |
| 답을 찾지 못했습니다 | 클로드가 준 답에 `{"answers": …}` 가 들어 있는지 확인 |

## 설치 (아드님이 한 번)

1. Python 3.12 를 python.org 에서 설치합니다('Add python.exe to PATH' 체크).
2. 코드를 받습니다: `git clone https://github.com/yhlee217/kafa` (또는 GitHub 에서 ZIP).
3. 그 폴더에서 `py -m pip install -e .`
4. 아드님 Mac 의 **처리 이력** `~/kafa-out/kafa.db` 와 **수임처 속성** `~/.kafa/clients.yaml` 을
   USB 등으로 아버님 PC 에 옮깁니다(수임처 이름이 들어 있습니다 — 메일·클라우드에 올리지 않기).
5. `py -m kafa.desk_cli setup --import-db <옮긴 kafa.db> --import-clients <옮긴 clients.yaml>`
   - `kafa` 폴더, 수임처별 받은자료 폴더, `처리하기.bat` · `업로드본_만들기.bat` 이 생깁니다.
   - 두 .bat 의 바로가기를 바탕화면에 두면 편합니다.
6. 옮긴 뒤로는 **아버님 PC 가 원본**입니다. 아드님 Mac 에서 같은 달을 따로 처리하지 않습니다(이력이 갈라집니다).

업데이트는 코드 폴더에서 `git pull` 한 줄입니다(아드님).
