## Phase 2 — 미추천 해소 (외부 LLM 없음)
시드 출처: ① 위하고 과거 처리분 전표(확보 시 `build_seed_index`) ② **자가 시딩**
(`build_seed_from_inputrows`) — 같은 다운로드 배치에서 위하고가 이미 채운 행의 차변계정을
코드로 매핑해 (거래처/사업자번호)별 최빈 계정 인덱스 구축. 외부 데이터 불필요.
추천 우선순위: 사업자번호 정확 → 거래처명 정확 → 거래처명 유사도(상한 0.60, 임계 0.80).
점유율을 신뢰도로. 근거 없으면 unresolved(담당자 확인).
