# kafa 사용법 — 쉽게 따라 하기

위하고 '신용카드' 화면에서 내려받은 엑셀(.xlsx)을 **위하고 업로드용 파일(.xls)**로 바꿔 줍니다.

**좋은 점**
- 어려운 명령어가 없습니다. **Claude Desktop(또는 Claude Code)에 말로 부탁**하면 됩니다.
- **추가 비용이 없습니다.** 이미 쓰고 계신 Claude 가 직접 처리합니다(별도 키·추가 요금 없음).
- 계정을 못 정한 '미추천' 건은 **Claude 가 업종·품명을 보고 대신 추천**하고 그 이유도 적어 줍니다.
- 사업자번호·거래처 이름 같은 **민감정보는 절대 밖으로 나가지 않습니다**(컴퓨터 안에서만 처리).

---

## 처음 한 번만: 연결 설정

1) 설치 (검은 화면[터미널]에 한 줄 입력):
```
pip install -e ".[mcp]"
```
2) Claude Desktop 설정 파일에 아래 내용을 넣고, Claude Desktop 을 껐다 켭니다.
   - 설정 파일 위치
     - 맥(Mac): `~/Library/Application Support/Claude/claude_desktop_config.json`
     - 윈도우: `%APPDATA%\Claude\claude_desktop_config.json`
```json
{
  "mcpServers": {
    "kafa": { "command": "kafa-mcp" }
  }
}
```
> 이 설정은 처음 한 번만 하면 됩니다. (Claude Code 를 쓰셔도 같은 방식으로 연결됩니다.)

---

## 매번: 이렇게 말하면 끝

Claude Desktop 대화창에 **파일 위치를 알려주며** 이렇게 말하세요:

> "바탕화면 `카드` 폴더의 `3월.xlsx` 를 변환해서 같은 폴더의 `출력` 에 넣어줘."

그러면 Claude 가 알아서:
1. 파일을 살펴보고(미추천 건이 있으면 업종·품명을 보고 **계정을 추천**),
2. 위하고 업로드용 `3월_upload.xls` 를 만들고,
3. 한국어로 결과를 알려 줍니다. 예:
   > "끝났습니다. `출력` 폴더에 **3월_upload.xls** 를 만들었어요(120건).
   > 그중 **5건은 확인이 필요**합니다 — `3월_review.txt` 에 적어 두었어요.
   > 이 파일을 위하고 '신용카드 매입 엑셀 업로드'에 올리시면 됩니다."

**점검만 먼저** 하고 싶으면: "그 파일 먼저 살펴봐줘" → 건수·미추천 수만 보여 줍니다.

---

## 결과 파일 (출력 폴더에 생깁니다)
| 파일 | 무엇 |
|---|---|
| `*_upload.xls` | **위하고에 올릴 파일** (너무 크면 `_part01.xls`로 나뉨) |
| `*_review.txt` | **확인이 필요한 건** 요약(미추천·검토·이상 거래처) |
| `*_review.csv` | 건별 분류 내역과 **추천 이유**(꼼꼼히 대조하실 때) |

## 막힐 때
- "위하고 파일이 아니라고 나와요" → 위하고 '신용카드' 화면에서 받은 .xlsx 가 맞는지 확인하세요.
- 빨간/검토 표시가 있는 건은 **사람이 한 번 봐야 하는 항목**입니다(예: 주유소=비영업용 의심).

---

## (참고) 명령어로 쓰기 — 자동화/일괄용
Claude 없이 컴퓨터가 알아서 돌리는 방식입니다. 이때 미추천 추천은 컴퓨터 안의 규칙으로만 합니다.
```
python -m kafa.cli <입력폴더|파일.xlsx> <출력폴더> [--client-type corporate|individual] [--truth 정답.csv]
```

## (참고·선택) 별도 API 로 추정하기
기본은 위처럼 **이미 켜진 Claude** 가 추정하므로 추가 비용이 없습니다. 자동 배치에서 사람이
개입하지 않고 AI 추정을 쓰고 싶을 때만, `config/rules.yaml` 의 `recommend.llm.enabled: true`
로 켜고 환경변수 `ANTHROPIC_API_KEY` 를 설정합니다(이 경우에만 별도 토큰 비용 발생).

## 보장
- **오차 없음/고정 양식**: 변환·코드화는 컴퓨터의 정해진 규칙이 수행하고, 출력은 고정 양식으로만.
- **추가 비용 없음**: 미추천 추천은 이미 쓰고 계신 Claude 가 수행(별도 키 불필요).
- **보안**: 거래처 이름·사업자번호는 AI 에 전달하지 않음(업종/품명/유형만 사용).
